# vizitka.me

Сервис быстрого портфолио-визитки. Мастер вводит тезисы и фото своих работ,
ИИ помогает оформить текст, на выходе — аккуратная публичная страница по ссылке.

Личный некоммерческий проект. Для бьюти-мастеров, фотографов, репетиторов,
мастеров по ремонту в СНГ/Казахстане.

## Как это работает

1. `/create` — форма: профиль, фото, список работ, формат отображения.
2. `/api/generate` — ИИ (Claude) причёсывает био и описания работ (черновик, финал за пользователем).
3. Публикация → приватная ссылка-токен для правок + публичная ссылка `/{slug}`.
4. `/edit/{token}` — вернуться и отредактировать в любой момент (без аккаунта/пароля).

Три формата отображения работ: галерея фото, кейсы с текстом, «До / После».

## Стек

- Next.js 16 (App Router) + React 19
- shadcn/ui (временно — планируется замена на собственную дизайн-систему)
- SQLite (better-sqlite3), файлы БД и картинок — на диске
- Claude API (`@anthropic-ai/sdk`) для оформления текста

## Локальный запуск

```bash
npm install
npm run dev   # http://localhost:3000
```

БД и загрузки складываются в `./data` (git-ignored).

## Переменные окружения

См. `.env.example`. Обе необязательны локально:

- `DATA_DIR` — где хранить БД и картинки (на Railway — `/data`, том).
- `ANTHROPIC_API_KEY` — включает ИИ-оформление. Без него текст копируется как есть.

## Деплой (Railway)

- Nixpacks автоопределяет Next.js.
- Примонтировать Volume на `/data`, задать `DATA_DIR=/data`.
- Опционально задать `ANTHROPIC_API_KEY`.
